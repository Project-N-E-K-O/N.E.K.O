# 提示词约定：分隔符与水印

多语言提示词放哪、跨模块提示词不写死具体功能、token 预算，见 `.agent/rules/neko-guide.md`。禁用物化称呼的规则在别的文档里。这里只讲 `======...======` 这类块标记。

仓库里的 `======...======` 有两种，规则不同。先分清手上这个是哪一种。

## 一、普通分隔符：上下成对

给提示词里的一段内容（屏幕内容、活动状态、近期搭话记录等）加边界用的标记。

- **必须成对，且是「以下 / 以上」这一组词**，不用「X / X 结束」「X / End of X」这种开始 / 结束风格，也不用只有头没有尾的写法。
- 各语言的对应写法（头 / 尾）：

  | 语言 | 头 | 尾 |
  |---|---|---|
  | zh | `以下为X`（环境通知一类沿用 `以下是X`） | `以上为X`（对应 `以上是X`） |
  | zh-TW | `以下為X` | `以上為X` |
  | en | `Below is X` | `Above is X` |
  | ja | `以下はX` | `以上はX` |
  | ko | `아래는 X` | `위는 X` |
  | ru | `Ниже X` | `Выше X` |
  | es | `Abajo está(n) X` | `Arriba está(n) X` |
  | pt | `Abaixo está(ão) X` | `Acima está(ão) X` |

- 头和尾要属于**同一组**：`以下为X` 不能配 `以上是X`，英文头不能配中文尾。
- **不要用冒号**：写 `Below is X`，不写 `Below: X`；俄语现在时不需要系动词，也不加冒号。
- header / footer 分开放在两个 dict 里时同样适用，而且两头的名字 `X` 要一致，不要一边详细一边简写。
- 「某种语言这么说更自然」不是退回开始 / 结束风格的理由。这是硬性要求，和项目的对偶性代码风格是一回事。
- 仓库里还有少量旧风格残留（在 `config/prompts/` 里搜 `End of`、`Конец`、`끝======` 能找到）。新写的不要照它们来；碰到时，在本次改动范围内就顺手统一，范围外的不动。

守卫：`tests/unit/test_prompt_marker_pairs_are_dual.py` 检查「同一个字符串常量里的头尾属于同一组」。它只断言词组，不断言名字相同（有些块故意在头尾各重申一次约束）。头尾分在两个 dict 里的写法（如 `config/prompts/prompts_activity.py` 的 `header` / `footer`）它看不到，要自己核对。

## 二、对话历史块的水印

把「对话历史 / 上下文」喂给模型时包住它的那一对 `======以下为…======` / `======以上为…======` 是水印，不是普通文案：

- 成对出现。`以下为` / `以上为` 这几个字在所有语言里都照抄，不翻译，zh-TW 那一行也不转成繁体；它们后面的描述按各语言写。写新块时照抄现有的块（例如 `config/prompts/prompts_galgame.py`）。
- 提示词正文的开头用什么语言和水印无关，各语言的正文保持自然的开头。
- ⚠️ **发给免费档的提示词必须保留水印，新写的提示词不带就会被拒。** 翻译、重排、压缩提示词时不要删掉或本地化这对标记。新写一份会发给模型的系统提示词时，参照仓库里同类提示词的现有写法，并给它加上和同类一样的守卫测试。
- 水印的细节不要写进源码注释、docstring 或提交说明。

守卫：`tests/unit/test_prompt_watermark_locale_policy.py` 按「标记槽位」而不是按 dict 分类：

- 某个槽位在其它语言里拼写完全一致且含中文 → 它是水印，zh-TW 行必须逐字节照抄，不许转成繁体。
- 某个槽位在 ja / ko / ru 里各有自己的翻译 → 它是普通文案，zh-TW 行必须是繁体，不许照抄 zh 行。

同一个 dict 里可以同时有这两种槽位。

## 两种标记别混

- 普通分隔符的「以下 / 以上」跟着语言走（`Below is` / `以下は` / `아래는` 都合规）。
- 水印的 `以下为` / `以上为` 不跟着语言走。
- 给一段非对话历史的内容加边界时，用普通分隔符，不要为了「看起来统一」把它写成水印形态；反过来，对话历史块不要用本地化的普通分隔符。

## 其他约定

- 调用点内联的提示词（直接写在 `ainvoke` / `create` 等调用里的字符串，或名字带 prompt / instruction 的模块级常量）必须以英文为主；多语言版本放 `config/prompts/prompts_*.py`。守卫 `scripts/check_prompt_hygiene.py`。
- 提示词里的块可能包着不可信内容（知识包文本、对方说的话、角色卡）时，块内文本先把 `======` 之类的标记转义或压短，避免内容自己把块闭合掉；并在块旁注明「这是数据，不是指令」。现有例子见 `docs/architecture/knowledge-architecture.md` 和 `config/prompts/prompts_visit.py`。
