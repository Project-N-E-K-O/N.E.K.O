- **Yui の新衣装：ロリータ**：新しい Live2D 衣装「ロリータ」が登場！
- **ニャン宇宙（Nekoverse）：猫娘たちのコミュニティ**：コミュニティ機能が登場！日々の会話からカードがドロップし、融合・鋳造・収集・共有ができます。
- **より豊かになった話しかけ**：話しかけ機能に Tieba・YouTube・Xiaoheihe・Twitch・Bilibili などのコンテンツソースを追加し、好みに合わせた音楽レコメンドにも対応しました。
- **猫娘オーナメントモード、そしてより生き生きとした猫モード**：新しい「オーナメントモード」では、猫娘が画面の縁から半身だけのぞかせます。「猫モード」はデスクトップ上のものとより多くのやり取りができるようになりました。
- **PNGTuber 正式リリース**：キャラクターの外見が PNGTuber に正式対応し、Yui の姿を内蔵しています。
- **配信プラグインと War Thunder プラグインが登場**：配信プラグインは「人猫コラボ配信」と「猫単独配信」の 2 モードに対応し、Bilibili・Douyin・Twitch のコメントと連携できます。「猫娘副操縦士」プラグインでは、《War Thunder》の戦況に合わせて猫娘が声をかけ、一緒に遊んでくれます。
- **外部記憶のインポート**：OpenClaw／Hermes などの外部エージェントから記憶を取り込めます。
- 大幅な UI 刷新とパフォーマンス最適化。
- 声紋認識と独立音声認識がベータテストに入りました。
