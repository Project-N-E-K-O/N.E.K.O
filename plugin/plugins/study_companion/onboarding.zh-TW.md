這份指南對應伴學主介面的首次使用流程，幫助新使用者按順序完成模式選擇、目標設定、首次學習記錄和複盤匯出。

## 1. 選擇學習模式

- 伴學：閱讀或解題時需要快速解釋，優先使用這個模式。
- 互動：希望外掛出題、追問並檢查答案時使用。
- 教學：需要分步驟講解和引導練習時使用。

不確定時先從伴學模式開始。之後可以隨時在伴學介面的模式按鈕裡切換。

## 2. 設定每日目標

開啟每日目標編輯器，選擇適合目前學習情境的目標：

- 卡片：適合單字、公式、短知識點。
- 分鐘：適合專注閱讀或集中解題。
- 次數：適合背誦、口述或重複練習。

如果使用記憶卡組，開始專注前先開啟記憶卡組面板並綁定卡組目標。

## 3. 記錄第一條學習內容

可以把文字貼到伴學介面，也可以點擊 OCR 讀取目前螢幕內容。隨後選擇主要操作：

- 解釋：把目前文字轉成簡短說明。
- 生成題目：根據目前材料生成檢查題。
- 評估答案：把你的答案和題目進行比對，並返回回饋。

如果 OCR 不可用，請查看依賴狀態，並在外掛介面裡安裝缺少的 OCR 後端。

## 4. 複盤與匯出

學習結束後，開啟總結面板查看已完成和未完成的目標。先在外掛設定裡啟用筆記匯出，再把最近的學習材料匯出為 Markdown、PDF 或 DOCX。XMind 匯出還需要同時啟用 `doc_export.xmind_enabled` 設定項。

下一次學習前，可以透過知識圖譜和記憶卡組面板查找薄弱知識點和待複習卡片。

## 空狀態

- 知識圖譜沒有主題：表示外掛還沒有記錄到足夠的解釋或答題資料。
- 記憶卡組沒有卡片：需要先建立或匯入卡片。
- 學習記錄沒有最近事件：表示還沒有完成解釋、出題或評估操作。
- 匯出沒有筆記：表示最近的學習材料還不足以生成匯出內容。

## 錯誤狀態

- OCR 失敗：檢查螢幕擷取權限和 OCR 依賴。
- LLM 逾時：檢查已設定模型和網路後重試。
- 匯出失敗：先重試一次；如果仍失敗，先匯出 Markdown 再外部轉換。
- 缺少答案或題目：評估答案前，先生成或輸入題目。
