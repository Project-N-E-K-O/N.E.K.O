# 网易云点歌插件

## 账号与云端音乐库

`cloud_music` 支持账号昵称/ID/会员类型、本人创建与收藏他人的歌单、歌单曲目、喜欢的音乐、每日推荐、收藏歌手。查询默认每页20项，最多50项，返回下一页偏移；不会把整个账号音乐库注入聊天。

可以按精确名称或ID播放账号歌单（一次最多载入1000首），播放喜欢的音乐和日推；可以创建云端歌单、把指定歌曲/当前歌曲添加到本人歌单、移除歌曲、加红心或取消红心。保存整组队列必须明确要求整组。新歌单默认私人，创建、添加、移除和红心操作均读回核验；不修改他人创建的歌单，不猜测同名歌单。

例：“列出我网易云收藏的歌单”“看看网易云Rock歌单里面有哪些歌”“播放我网易云的Rock歌单”“把这首加入网易云的Rock歌单”“在网易云新建私人歌单夜跑”。收藏默认保存到网易云：“收藏这首”点红心；指定歌单就加入对应云端歌单，无需再指定“网易云”。只有明确说“本地”才使用 `playlist` 保存为角色本地数据，两处不自动同步。简体、繁体和英文请求使用相同的收藏操作校验；拒绝或询问操作方法的句子不授权修改。角色主动台词不能触发云端或本地保存。执行端同时校验编排器传入的请求来源和用户原话，模型提供的 `_ctx` 不能覆盖这两项。

云端歌单按完整名称或 ID 精确查找；完整名称不存在时返回未找到，不自动删去名称末尾的“歌单”再操作另一张列表。停止、切歌入口在云端查询筛选后仍然保留，收藏并切歌的请求可同时看到对应入口。

聊天主模型只收到一条简短的音乐能力提示。后台执行器按当前请求选择 `cloud_music` 的操作及字段，其他操作说明不会出现在本轮参数描述中；普通点歌、公开歌单搜索和非音乐对话不加载云端操作说明。操作结果由后台回传，必须等真实结果再回答。


启用任务分析和用户插件通道、启动本插件后即可在聊天里点歌。明确点名或“挑一首”只播一曲。说“放点歌”时，角色根据当前聊天和记忆中的音乐偏好编排曲目；说“搜网易云的 dream pop 歌单”按原歌单顺序播放。精确匹配歌名和指定的歌手，没有匹配时不播放其他版本。

“把这首加到本地歌单夜读”只收藏播放器确认的当前曲目，按歌曲 ID 去重；回执包含歌名、歌手和收藏后的总数。“把整张歌单保存为本地歌单夜读”把当前整组曲目的网易云 ID、歌名、歌手保存在角色自己的本地收藏。“播放本地歌单夜读”“下一首”“停止连播”可直接控制。自然结束或加载错误推进一次，关闭播放器终止连播。每首临播放时解析音源。

本地歌单使用保存时的完整名称。当收藏库同时存在“夜读”和“夜读歌单”这类名称时，后端先返回 `playlist_name_ambiguous` 和候选列表，保留当前播放。用户明确选定后，重播入口携带 `name_confirmed=true` 才会播放；确认标记仅在当前角色确实收到过同一组候选、且没有被较新的播放或停止请求取代时生效；首次请求即使误带该标记也不会直接播放。重播时未提供名称或找不到对应歌单，会列出当前角色已经保存的歌单，请选择其中一个；当前播放队列继续保留。名称本身含有“歌单”或“点歌台”时也会完整保留。明确要求使用点歌台或本地音频文件时，交给点歌台控制器。

## 路由补测

配置好 summary 模型后，在仓库根目录运行以下命令，可用真实模型检查本地歌单与点歌台的入口选择、参数和对话中的名称纠正。脚本只分析合成对话，不执行播放、收藏或桌面操作；模型调用会消耗 token。每次使用一个新的输出目录，结果包含模型、代码提交、提示词摘要和逐例判断。

```sh
uv run python scripts/probe_music_routing.py --pipeline --repeat 2 --output /tmp/neko-music-routing
```

这项补测固定提供网易云与点歌台两个插件，使用中文路由提示；不覆盖完整插件清单筛选、记忆服务、前端触发或音源播放验收。

## Cookie 配置

插件管理页内置 Hosted UI Cookie 配置面板，字段与内置网易云登录保持一致：`MUSIC_U` 必填，`NMTID` 可选。`MUSIC_U` 输入框既可粘贴单独值，也可粘贴包含 `MUSIC_U=...` 的完整 Cookie 字符串；完整字符串中的 `MUSIC_A`、`NMTID` 和 `__csrf` 也会一并保留，其余 Cookie 会被丢弃。

获取方式也直接写在插件面板中：登录 `music.163.com` 后打开浏览器开发者工具，在 Application（应用程序）→ Storage（存储）→ Cookies → `music.163.com` 中复制 `MUSIC_U` 和可选的 `NMTID` 的 Value。插件不会尝试读取浏览器 Cookie。

凭据只会加密保存在本插件的私有数据目录，面板只返回配置状态和保存字段数量，不会回显 Cookie。保存后无需重启，后续点歌会先将这些 Cookie 同步到插件创建的 pyncm 会话并尝试登录音源；凭据失效、请求异常或没有返回音源时，会自动降级到已验证的公开音源。清除后立即恢复匿名解析。

## 安全与隐私

- 搜索地址固定为网易云公开搜索接口，播放地址只能由验证过的十进制歌曲 ID 构造。
- 所有实际网络请求和最终播放地址均为 HTTPS；重定向的每一跳都会校验网易云域名。
- 插件不接受模型传入播放 URL，不读取 NEKO 全局凭据、浏览器或系统 Cookie，不继承环境代理；只使用用户在本插件 Hosted UI 中保存的网易云 Cookie 白名单字段。
- 插件日志、结果消息和错误中不输出完整音频 URL、签名查询串、Cookie 或响应体。
- 播放动作只发送给调用上下文中的 `lanlan_name`；缺少目标会话时直接拒绝，避免广播到其他角色。
