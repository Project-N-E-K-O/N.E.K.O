### 组合冲突的处理

- final 接受与队列入队沿用 #3149 的同步提交，先于 SmartTurn lease 释放。#3219 的队列 turn token 和背压保留契约接入现有投递所有权；不把已入队 final 再登记为尚未提交的预留槽，也不重复提交或放弃它。源测试通过受控投递事件及真实 abort 入口验证背压、取消和关麦，而非假定 lease 释放前尚未开始派发。
- 检测器同时保留本分支的 admission 确认与源 PR 的 epoch/语义身份检查：未准入和旧 epoch 的完成结果都不能封闭后继回合。
- 声纹页面保留录入结果卡片、约 1.5 秒有效人声手动保存与链路恢复；叠加 off 模式门控。八个语言包保留已有结果与恢复文案，加入功能禁用说明并删除声纹 shadow 模式文案，刷新页面资源和语言包缓存指纹。
- Qwen 本地模型不可用仍按源 PR 契约阻断，不自动回退 provider 判停；唤醒纠错仍只作用于已获资格的首轮 final。ASR 准入实验自身的 shadow/off/enforce 与声纹运行模式是不同概念。

## 冲突合并后的契约

- 独立 ASR 先对原始转写和证据判断准入，再对已接受的唤醒后首轮 final 做句首纠错。被拒绝的候选不进入 LLM/TTS；放弃回合时清理预览并结算对应暂停。
- 会话与 TTS 保留资源归属检查，同时保留主线的配额分类、限流退避、热切换投递回执和缓存去重。延迟重试既检查等待时长，也检查原 session 与 runtime 是否仍有效。
- 公共结束调用采用有界等待，安全交接与物理资源退出分别记账；已完成启动的长期 TTS handler 使用新的恢复预算。关闭失败的 WebSocket/Gemini 资源保留引用与容量，只在确认释放后销账；准备 token 绑定连接，旧连接迟到的结算不能释放新连接的暂停，取消票据可在暂停期间完成结算。
- 声纹页面以主线录入生命周期为基础，叠加结果卡片和有界链路状态恢复；取消、超时、BFCache 恢复和麦克风接管继续校验操作归属。
- 录音保存沿用主线的人声样本计数：达到约 1.5 秒有效语音后允许手动保存，固定 3/5 秒上传格式及后端校验不变。保留提示语提前显示、下一段进度和无障碍对比度修复。
- 网页与 Electron 共用同一套声纹资源和八个语言包；合并后的静态资源及语言包使用新的缓存版本。
