# 订阅与套餐

在 API 设置的「订阅与套餐」区，可以让一组文字功能改用某个订阅的额度：登录或填好订阅的 Key，勾选要交给它的功能并选好模型，再打开「使用这个订阅」。关掉开关，这些功能就回到原来的设置。

## 原来的设置不会被改动

订阅状态单独保存在本机 state 目录的 `subscriptions.json`，不写进 `core_config.json`，也不进入云存档。「保存设置」不会改动订阅状态，订阅面板也不会改动「按功能单独指定模型」里的任何设置。所以打开、关闭订阅都不需要「恢复」原配置。换电脑或从云存档恢复后，需要重新登录订阅、重新打开开关。

## 谁说了算

每个文字功能按下面的顺序决定用什么：

1. 「按功能单独指定模型」里这一项单独设置好、并且正在生效：开了「开启按功能单独指定模型」，服务商选的是具体服务商或自定义（不是跟随），地址和模型都填了。
2. 订阅与套餐里接管了这一项的订阅。
3. 跟随（例如小游戏聊天模型默认跟随聊天模型）和上方的通用模型供应商。

跟随别的功能的项，会跟着被跟随的那一项走：聊天模型交给订阅后，没有单独设置的小游戏聊天模型也走同一个订阅。

被订阅接管的功能，在「按功能单独指定模型」里会显示「订阅 · 名称」标签和一行说明，下面的设置照常可以修改和保存，关掉订阅后恢复使用；这期间它的连通性指示灯不代表实际在用的配置。通用模型供应商下方会列出正在走订阅的功能。

## 可以交给订阅的功能

聊天模型、记忆整理（大模型）、识别模型（小模型）、使魔模型·通用 / 小型 / 高级、小游戏聊天 / 记忆 / 识别模型。每个订阅实际开放哪些，按它包含的模型而定：模型不能看图的订阅不开放聊天模型。决策模型、实时语音、语音合成、语音识别和图片生成继续用各自的服务商。

一个功能同一时间只属于一个订阅。在另一个订阅里勾选已被接管的功能，会先确认，再从原来的订阅移过去。

## 打开、关闭和失效

| 情况 | 结果 |
| --- | --- |
| 打开订阅 | 需要先登录或填好 Key，并至少勾选一项功能 |
| 关闭订阅 | 勾选和模型选择保留，下次打开直接恢复；功能回到原来的设置 |
| 取消勾选某一项 | 只有这一项回到原来的设置 |
| 退出最后一个 ChatGPT 账号、删除订阅的 Key | 这个订阅自动关闭，功能回到原来的设置 |
| 订阅过期、额度用完、授权被撤销 | 订阅保持打开，请求报错并提示原因；不会悄悄改用按量计费的 API Key |

打开或关闭订阅后，新的请求立即按新设置走；正在进行的对话在会话结束后改用新设置。

## 套餐的 Key

需要 Key 的套餐，Key 保存在 `subscriptions.json`，不会返回给设置页面。MiMo Token Plan 如果已经在「通用模型供应商」里填过 Token Plan Key，订阅卡片不填 Key 时会直接使用那一把。

## 各订阅

- **ChatGPT**：登录方式见 [ChatGPT 订阅接入](/zh-CN/config/chatgpt)，模型列表按登录的账号拉取。
- **MiMo Token Plan**：选择中国大陆、新加坡或欧洲集群，填 `tp-` 开头的 Key。

标「未实测」的订阅还没用真实订阅测试过，遇到问题请反馈。

## 性能

`core_config.json` 和 `subscriptions.json` 在进程内缓存：本程序写入时立即失效；不经过本程序写入的改动（手改文件、云存档恢复等），在读取配置时最多每 2 秒核对一次修改时间，最多晚 2 秒生效。没有后台定时器。
