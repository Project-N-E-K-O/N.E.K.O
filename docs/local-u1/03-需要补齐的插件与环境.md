# 本地版 u1 — 需要补齐的插件与环境

合入或试用本改动前，请自行准备以下依赖（**仓库不包含**大模型权重与 RVC 训练产物）。

## 必补（本地文本 / 视觉 / 语音）

| 项目 | 说明 |
|------|------|
| Python 3.11 + uv / `.venv` | 可用 `install_env.bat` 或官方 `uv sync` |
| [Ollama](https://ollama.com) | 本机 `11434`；拉取文本模型 + 视觉模型（如 `llava`） |
| `set_local_ai.bat` | 将 assist 文本/视觉指到 Ollama，TTS 指到 Edge 桥 |
| Edge TTS 桥 | `scripts/edge_tts_bridge.py`（`start_edge_tts.bat`），默认 `19000` |
| ffmpeg | Edge TTS 转码依赖 |
| faster-whisper | 本地麦克风 ASR（`install_local_asr.bat`）；首次会下载 Whisper 权重 |

## RVC 翻唱（可选，但要用插件则必补）

| 项目 | 说明 |
|------|------|
| `scripts/setup_rvc_vendor.ps1` | 从本机 RVC 安装同步到 `vendor/rvc`（**不修改**原 `D:\RVC`） |
| RVC runtime + 推理权重 | 位于 `vendor/rvc/runtime`、`assets`（gitignore，需本地同步） |
| CUDA（推荐） | 加速 RVC / 部分 ASR |
| 训练（可选） | `scripts/start_rvc_training.bat`；训练输出在 `vendor/rvc/logs`，**不要提交** |

## 前端构建（改插件管理 UI 时）

| 项目 | 说明 |
|------|------|
| Node.js LTS | `build_frontend.bat` / 官方文档 `npm ci` |
| 构建产物 | `static/react/neko-chat`、`frontend/plugin-manager/dist` 默认不入库 |

## 明确不需要 / 不要提交

- 个人 API Key、`api_providers.json` 本地密钥
- QQ / B 站插件个人 profiles、`.runtime_state.json`
- `vendor/rvc/logs` 训练实验、`.models` 缓存、`desktop_release` Electron 拷贝
- AIYS 壳种子配置（勿把 `assistApi` 写成非法的 `ollama` 字符串）

## 建议验证顺序

1. `uv sync` 或 `install_env.bat`
2. 启动 Ollama，确认文本 + 视觉模型可用
3. `set_local_ai.bat` → 重启桌面 / launcher
4. 打开 `/health`，试一轮文字聊天与视觉
5. （可选）`setup_rvc_vendor.ps1` 后启用 `rvc_cover` 插件试唱
