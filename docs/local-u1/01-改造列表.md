# 本地版 u1 — 改造列表

1. **双语语音协议**  
   聊天显示中文、TTS 播日语；支持 `<ja>…</ja><zh>…</zh>` 标签与启发式拆分，含脚本安全门（纯中文不进 TTS）。

2. **TTS 日语闸门**  
   新闻 / 主动陪聊 / 镜像播报等路径，在送入 TTS 前将非日语文本转为日语（不改动主对话流式双标签协议本身）。

3. **戳一戳中文气泡**  
   Avatar 交互有语音但聊天区为空时，在 flush 阶段将日语 TTS 内容翻译为中文写入聊天气泡。

4. **角色卡 vs 用户档案称呼**  
   角色卡表示 AI 身份；个人档案「档案名」用于称呼用户；payload 组装顺序调整。

5. **RVC 翻唱插件 `rvc_cover`**  
   说「给我唱一首…」时搜歌并用本机 `vendor/rvc` 音色翻唱；插件 id/type 为 `rvc_cover` / `plugin`（非 YS 前缀）。助手通过 `/runs` 协议触发，不修改用户原有 `D:\RVC` 安装。

6. **本地桌面启动**  
   `start_desktop*.bat|vbs`、环境安装与静默拉起辅助脚本。

7. **本地 AI / ASR**  
   Ollama 文本+视觉配置脚本（`set_local_ai`）、Edge TTS 桥、faster-whisper 本地 ASR worker。

8. **插件管理前端小改**  
   配合插件启停 / 面板展示（含 RVC 训练入口相关 UI）。
