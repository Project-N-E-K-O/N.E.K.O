# 点击引导版新手教程：开发与验证

## 产品边界

点击版是与七天教程并存的一次性入门引导。新用户首次启动仍只走原七日教程，不弹出选择。老用户从记忆浏览器点击“重新激活教程”后，才选择点击引导或重新开始七日教程；点击版保留七日进度。路线按“胶囊整体 → 胶囊细节 → 悬浮按钮整体 → 各主入口”连续推进，具体顺序见 [引导顺序](guided-onboarding-sequence.md)。

教程介绍入口与返回方式。首步要求用户自己输入“你好”并按回车发送，发出后接续聊天历史；已有草稿或附件时保留并允许跳过发送。开启麦克风、授权屏幕共享、执行 Agent 任务、选择文件或修改设置不作为完成条件。用户主动产生的草稿、附件和设置变更保留；教学临时展示状态在退出时恢复。

## 网页模块

模块位于 `static/tutorial/click-guide/`，统一由 `templates/_click_guide_scripts.html` 加载。

| 模块 | 职责 |
| --- | --- |
| `mask.js` | 整屏 SVG 绘制圆角矩形或圆形开孔；历史收起步骤支持第二个可见开孔，阻挡区域仍只放行当前可点击目标。 |
| `highlight.js` | 复用七日教程矩形框、圆形图片与 Ghost Cursor；与开孔共用几何范围，可展示第二高亮框并将光标放在目标按钮中央。 |
| `target.js` | 解析可见目标，跟踪移动、变形和窗口尺寸；支持独立的可见聚焦区域。 |
| `advance.js` | 捕获真实点击与键盘操作，按步骤决定是否拦截按钮业务点击；需要真实业务结果的步骤支持等待、取消与超时。轮盘悬停步骤由运行器观察轮盘的实际展开状态。 |
| `runner.js` | 步骤、临时视图、访问历史、“上一步”、章节进度、卡片避让、键盘导航与退出清理。 |
| `opened-window.js` | 在当前步骤内观察打开和复用的窗口，处理同源子页返回、嵌套窗口、关闭确认与观察器恢复。 |
| `native.js` | 把呈现数据交给桌面原生窗口，处理动作回执和生命周期。 |
| `state.js` | 等待存储启动闸门，读写带 CSRF 与版本号的服务端进度。 |
| `home-steps.js` | 首页业务适配：真实按钮选择器、顺序、返回视图、准备与恢复。 |
| `reactivation.js` | 记忆浏览器的重新激活选择、取消与保存失败重试。 |
| `home.js` | 显式点击版重新激活、两个阶段编排、桌面跨窗口协调和最终进度写入。 |

通用模块不包含聊天工具名称或首页业务选择器。页面适配层把现有入口、事件和状态判断传入通用模块。

## 步骤契约

```js
NekoClickGuide.createRunner({
    labels: { tour, section, next, back, skip, unavailable },
    steps: [{
        id: 'open-panel',
        title, body,
        target: '#actual-button',
        advanceOnClick: true,
        requireClick: true,
        ready: () => panelIsVisible(),
        enter: async signal => {
            // 准备本页的教学展示，返回对应清理函数。
            return () => restorePresentation();
        }
    }],
    onEnd: reason => saveResult(reason)
}).start();
```

- `target` 可以是选择器、元素或解析函数；`shape`、`padding`、`focusRect`、`radiusMode` 控制高亮范围。真实点击仍由原控件处理。
- `secondaryTarget` 可指定只展示、不接收点击的第二块区域；`secondaryShape`、`secondaryPadding`、`secondaryFocusRect` 控制其开孔与高亮。`cursorTarget` 将 Ghost Cursor 定位到组高亮中的实际按钮中央。
- `advanceOnClick` / `advanceOnHover` / `advanceOnKey` 观察用户真实操作，`ready` 确认需要实际执行的业务结果。`consumeTargetClick` 只在指定步骤捕获并阻止目标按钮的业务点击，同时把该次点击当成推进操作。`keyTarget`、`keyReady` 限定真实输入框内的回车发送；`requireInput` / `requireClick` 禁用普通下一步。目标不可用或超时后提供继续通道。
- `acceptTargetClick` 可限定组高亮中哪些子按钮能推进。悬浮按钮总览仅接受五个真实主按钮，点击被引导消费，不触发语音、Agent、社交、设置或回窝。
- `when` 只在到达该步骤时执行。跳过计数同时从当前序号与总数扣除，不为了计算进度提前调用业务判断。`labels.section` 区分聊天框和角色按钮两个阶段。
- “上一步”按实际访问历史返回，不重新计入条件跳过。`startIndex`、`initialHistory` 与 `initialSkipped` 用于跨窗口恢复；悬浮 1/9 返回胶囊最后一步时，主页重新进入聊天阶段并保留先前访问顺序。
- `nextLabel` 指定卡片动作；`onAdvance({by, signal})` 区分目标操作与卡片继续。`cardAvoid` 避让展开菜单或工具轮盘的完整范围。
- `view()` 提供当前步骤内部的临时返回视图。默认关闭后继续下一功能；`resume: true` 可在返回上一层时留在当前步骤。轮盘七个工具不用返回视图。
- `windowGuide` 声明子页返回文案与真实关闭入口。`nativeTarget` 声明由桌面解析的独立目标，当前用于原生毛绒球。
- 每步离开先取消监听与等待、停止几何跟踪，再执行清理。完成、跳过和失败都释放显示层；失败不写入完成记录。

点击监听在捕获阶段保存当时的视图。普通步骤等控件执行原操作后再判断 `ready`；轮盘七个介绍步骤在捕获阶段阻止当前高亮按钮的点击冒泡与默认动作，随后只推进教程。监听随该步骤的取消信号移除，教程外不影响原按钮。

`presentation` 只替换视觉承载，提供 `bind(actions)`、`update(frame)`、`close()`。网页使用 DOM；桌面接收相同几何、文案与推进状态。

## 视觉规范

开孔使用单层 SVG 裁切，高亮在遮罩上方、提示卡片下方；二者共用坐标与圆角。一般步骤取消内缩、尺寸过渡和缩放脉冲，避免描边与开孔分离。历史条通过 `focusRect` 测量 `::before` 的可见蓝线；2/13 初始只在展开条上显示 Ghost Cursor，点击后立即扩大开孔，高亮框在 0.3 秒内展开到记录面板，短暂展示时隐藏光标；3/13 保持面板可见高亮，同时以第二开孔/高亮框聚焦蓝色收起条。收起条高亮及 Ghost Cursor 叠在记录区高亮之上，记录区高亮本身不带光标。胶囊总览使用 `padding: 0` 与目标本身的圆角。圆形复用七日教程现有图片，不额外叠加猫耳。需要点击时 Ghost Cursor 位于真实按钮中央；张开和点击两张猫爪图片互斥切换，不叠在一起。

背景资源为 `static/assets/tutorial/click-guide/card-background.png`，直接使用用户提供的原图。网页卡片与桌面原生卡片把图片画在卡片本身的背景上，并在其上叠加 65% 不透明的浅色或深色渐变，得到约 35% 的图片可见度；文字和按钮保持不透明。这样背景覆盖预留的滚动条区域，右侧不再露出空白带；移除卡片顶部装饰线和外边框。选择卡片与子页返回卡片遵守同一规则。桌面通过运行时页面 origin 生成绝对资源地址，不把资源地址写死到本地端口。

文案以当前可执行动作为主句，概览仅说明入口用途；轮盘和悬浮总览的高亮按钮明确提示“只推进引导，不执行功能”。同一套 `clickGuide` 文案维护八种语言。

卡片避开目标和整个轮盘。网页与桌面均预留稳定的滚动条宽度；桌面卡片按实际内容高度调整窗口，避免滚动条出现/消失改变换行、反复触发窗口高度变化。

## 打开、关闭与返回

轮盘七个工具在介绍时可点击高亮按钮或卡片“下一步”继续，不执行工具动作。悬浮按钮总览同样消费任意一个主按钮的点击，只推进到语音说明；后续具体入口仍允许真实打开菜单或页面。打开后临时切换为“认识入口 → 关闭返回”的说明，不增加固定编号，也不把关闭点击当成另一个功能的点击。

- 悬浮菜单：卡片通过原有接口收起菜单。设置或 Agent 打开页面时，切换到该页关闭说明。
- 网页窗口：步骤期间观察 `open` / `openOrFocusWindow`，保留原参数、返回值和安全策略；同源页面注入返回卡片与关闭高亮，嵌套页面先返回上层，最外层关闭后才完成当前步骤。
- 桌面窗口：跟随当前步骤实际打开的子窗口、已有导航事件指向的复用窗口和点歌台窗口；逐层关闭或隐藏后才返回父教程。
- 子页原有页面教程在检查期间暂停且不记为已看；检查结束并重新聚焦后，从被中断的步骤继续。
- 跨域页面不读取或注入 DOM，保留浏览器关闭方式，父教程可通过已有窗口引用请求关闭。弹窗被拦截时不进入等待关闭状态。
- 其他页面创建的共享窗口可能只返回代理句柄：卡片提示到已打开的页面手动关闭，按钮只聚焦该页面，不调用空的关闭方法；观察到实际关闭后继续。
- 卡片关闭优先调用页面既有关闭控件，保留保存确认；点击真实关闭控件也进入等待关闭状态。等待期间释放页面点击限制，用户可以处理确认或取消；窗口未关闭不提前推进。
- 结束引导释放教程显示、监听和临时观察器，不强行关闭业务页面。

同源子页通过临时标记与事件暂停 `core/page-tutorial-manager.js` 的页面教程，防止旧引导遮住关闭入口。暂停不消费手动重置意图，也不写入七日完成或跳过记录；结束检查后还原标记。

## 服务端进度与启动

`utils/click_guide_state.py` 在当前用户配置目录保存 `click_guide_state.json`，字段为 `version`、`revision`、`choice`、`status`、`pending`。

| 操作 | 结果 |
| --- | --- |
| `GET /api/click-guide/state` | 读取进度，默认七日，点击版仅由手动重新激活触发。 |
| `POST action: choose` | 保存 `click` 或 `seven-day`；点击版标记待开始。 |
| `POST action: finish` | 保存 `completed` 或 `skipped`，清除待开始。 |
| `POST action: reset` | 仅重置点击版为待开始，选择点击版，保留七日记录。 |

写入需携带 `expectedRevision`，冲突返回 409，防止旧窗口的完成回执覆盖刚发生的重置。沿用 CSRF、串行 worker 和原子 JSON 保存，没有额外 localStorage 进度副本。

点击状态写入复用 `nekoLocalMutationSecurity` 的 token 缓存，只有 403 `csrf_validation_failed` 才刷新并重试一次。chat 页不自动读取点击状态。模型启动并行等待七日与点击状态，避免点击重播与七日角色预测冲突。预测仅使用七日状态的只读投影；旧手动意图的实际清理只在主页等待七日同步后执行。无法识别的未来文件版本只返回只读默认状态，并拒绝修改，原文件保持不变。

主页从 `universal-manager.js` 调用 `handleStartup()`。仅在记忆浏览器明确选择点击版且待开始时接管启动。其余状态（含旧版未选择）继续原七日链路。点击版完成后恢复正常七日每日推进，一次性清除被更新点击选择替代的旧七日 manualResetRound/pendingRound，保留日期与完成/跳过记录；新的显式七日重置仍优先。启动预测器仅在点击版待开始时抑制七日角色预测，完成后与主页共用旧手动意图的只读投影，实际清理在主页同步完成后执行；未选择的新用户仍按原七日规则预测。七日的按日/全部重置成功后才取消待开始的点击版；点击状态 API 失败也不阻断原重置。选择保存 `selectedAt`，只有更新的七日手动重置记录可以覆盖点击模式，旧重置意图不会重新触发。旧点击状态首次读取时迁移时间并递增修订号。临时文件读取错误直接失败，不覆盖既有状态；仅缺失或损坏内容恢复默认值。

点击版使用 `isNekoClickGuideActive`，不设置旧教程的全局输入锁。人格选择、主动聊天和自动回窝在点击版期间等待，结束后走原启动释放事件；不发送七日完成事件。

## 桌面呈现与跨窗口协调

桌面需要配套使用 `N.E.K.O.-PC` 的实现。关键文件是 `src/click-guide-overlay-service.js`、`src/preload/entries/click-guide-overlay.js`、`src/preload/shared/common.js` 和 `src/ipc-channels.js`。

原生显示层由整屏 SVG 遮罩、四个透明点击阻挡窗口、高亮窗口、可交互卡片窗口组成。这些窗口挂到当前 Pet 或 Chat 所有者窗口；卡片的顶层相对层级高于遮罩和高亮，进入新步骤及所有者重新激活时重提卡片，避免锁定位置步骤被模型窗口遮住。遮罩与高亮忽略鼠标，空洞露出真实按钮；历史收起时额外绘制第二开孔与高亮框，透明阻挡窗口仍只放行蓝色收起条。隐藏网页中的高亮副本。坐标由所有者窗口 content bounds 和 zoom 换算，布局使用目标屏幕的 `workArea`，避免 macOS 菜单栏挤占顶边。

胶囊缩成毛绒球后，桌面使用独立球窗口的可见贴图范围，不使用较大的拖拽锚点或透明 React 载体。恢复步骤保留毛绒球高亮和提示卡片；毛绒球尚未出现时，卡片暂不显示，避免按无目标布局在屏幕中央闪现。回窝按钮切换到召回按钮时采用同一规则。目标出现后显示相应卡片；入口持续不可用时，超时后显示带“下一步”的兜底卡片。收到真实毛绒球 CLICK 回执且聊天状态恢复为 compact 后，才进入下一步。

主进程校验 Pet/React Chat 所有者、runId、递增序号及动作步骤号。所有者主文档导航、销毁、渲染退出或 6 秒未续期都会释放覆盖层；iframe 加载和同页导航不终止教程。复用窗口的相对 URL 按所有者当前地址解析，并限制在同一 origin。旧桌面桥缺少原生接口时可使用 DOM 呈现，但不能保证小型独立聊天窗口完整展示，因此桌面发布必须配套更新两个仓库。

主页和 `/chat` 使用独立 `click_guide` 消息：`start → ready → done`，并有 `heartbeat` 与 `stop`。优先走桌面 relay，同源网页可用 BroadcastChannel。聊天窗口准备完成才回 ready，失联不记为完成；复用已有聊天展示接管器，不复用七日剧情消息。

## 恢复边界

聊天阶段退出时恢复原聊天框开闭状态、聊天形态、历史展开状态及轮盘位置，收起临时道具栏并结束临时道具使用。悬浮阶段退出时恢复按钮标记、样式和原有菜单；锁图标在主按钮教学期间临时隐藏，到锁定步骤再显示。体验回窝后若中途退出，适配器恢复原来的角色在场状态。

用户主动修改的设置、草稿、附件与模式保留。社交解锁、正常聊天、拖拽和七日教程仍使用原业务语义。用户文案统一维护在 8 个 locale 的 `clickGuide` 子树。

刷新、pagehide 或聊天窗口失联按中断处理，不提交完成或跳过，下一次启动仍可重播；只有明确点击跳过才保存 skipped。运行标识在非安全 HTTP 环境也有生成兜底。

## 验证入口与范围

```sh
# N.E.K.O
uv run pytest tests/unit/test_click_guide_state.py tests/unit/test_seven_day_tutorial_state.py tests/unit/test_prompt_flow_router.py -q
node --test --test-force-exit tests/frontend/click-guide.test.cjs tests/frontend/tutorial-seven-day-state.test.cjs

# N.E.K.O.-PC
node --test test/click-guide-overlay.test.js
NEKO_GUIDE_WEB_ROOT=/path/to/N.E.K.O node --test test/integration/click-guide-overlay.test.js
```

网页测试覆盖步骤顺序、条件跳过、真实点击/悬停、返回视图、子页与嵌套窗口生命周期、关闭确认、退出清理及七日隔离。桌面单元测试覆盖布局与 IPC，真实 Electron 集成测试覆盖原生开孔/高亮、目标点击、卡片动作、独立毛球、子窗口关闭、长文案高度稳定与覆盖层释放。

运行时验收还需检查实际 `/chat` 的历史条、轮盘七次点击只推进，以及教程结束后道具栏、点歌台和导出的正常功能；还要检查主页设置打开的页面。Electron 集成测试使用临时应用、端口和隔离 userData；网页检查使用临时浏览器会话连接开发后端，不把浏览器隔离等同于后端数据隔离，也不通过重置 API 改写日常教程进度。

本功能网页代码是直接加载的静态脚本和 CSS；若改到 React 前端源码，另运行 `bash build_frontend.sh` 并确认页面引用的新产物。桌面主进程或 preload 修改后需重新构建 Webpack 产物。

自动化点击与孤立 Electron 测试不等同于完整桌面主应用的人工体验。Windows/Linux 真机、多显示器跨屏移动、四种模型全流程、系统级物理鼠标操作以及麦克风授权、屏幕分享、Agent 执行业务仍需分别验收；不要从网页测试结果推导这些范围已经通过。

当前验证：服务端相关单测 30 项、网页点击引导与七日状态测试 74 项、桌面单元测试 10 项、真实 Electron 集成测试 1 项通过。八语言 JSON 可解析且 `clickGuide` 的 137 个 key 一致。实际 `/chat` 页面与 Electron 截图已检查输入焦点、历史双高亮、Ghost Cursor 图片切换和卡片背景；目标暂时缺席时提示卡等待，毛绒球与回窝按钮出现后再显示。步骤稳定后主动同步原生卡片按钮状态，避免窗口被遮挡时动画帧暂停导致“下一步”持续禁用。React 源码未改，无需重建前端；桌面 Webpack 产物已更新。完整主应用的物理鼠标操作仍需人工体验。
