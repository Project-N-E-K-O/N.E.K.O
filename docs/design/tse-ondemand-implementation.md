## 下载与页面合同

- `GET /api/voice-identity/status` 返回独立的 `tse.model`、`reference_state`、`enabled`、`can_enable`、`runtime_state`、`reason`。
- `POST /api/voice-identity/models/tse/download` 选择应用固定资源。下载源为空时返回 `tse_source_unconfigured`，不创建虚假下载进度。
- `POST /api/voice-identity/models/tse/import` 接收 `application/zip` 原始流，共用同一校验与发布事务。
- `POST /api/voice-identity/tse` 接收 `{enabled, profile_id}`，检查档案代次、模型/参考和生产链路可用性。开关偏好有独立原子设置文件；首装不会自动开启。
- 服务拥有下载任务，页面关闭不取消下载；上传请求拥有本地导入迭代器，断开会取消导入。两类资源任务与录入互斥；多次点击下载复用任务。
- 全包与内部文件哈希、固定大小、ZIP 条目/展开量、路径与链接、模型 IO 合同通过后才发布完整版本目录。失败保留旧可用版本，旧代不能覆盖新任务状态或清理新任务目录。
- 八语言页面把 TSE 放在四段录入下方并默认收起；摘要只说明“多人说话时优先保留你的声音”，展开后显示模型、声纹、使用状态和必要操作。活动期使用同一个状态刷新计时器，隐藏/关闭页面停止刷新。

## 录入与档案

- 保留 CAM++ 四段录入及独立验证。开始时冻结已安装 PVAD/TSE 快照。
- TSE 只使用前三段通过校验的 3 秒参考。最多暂存 `3 × 48000 × 4 = 576000` 字节规范化 PCM，在本次录入的有界内存中使用；验证段不并入 TSE 参考。
- 通过 holdout 后，先等待现有 PVAD 编码器退出，再在受控独立进程生成 TSE 参考；主线程不执行 ORT/FFT。取消或超时后回收进程，清零拥有的音频/向量。
- 与计划仍有一项基线差异：现有 PVAD 合同使用第四段已验证的 5 秒音频生成其参考；本次 TSE 使用前三段，各 3 秒。没有修改并行开发中的 PVAD 合同，因此不能宣称“两套 ECAPA 均使用同三段参考”或“验证段完全不用于任何参考”。PVAD 侧是否迁移需与其稳定版本一并对齐。
- CAM++、可选 PVAD 和可选 TSE 绑定同一 Owner 代次，在同一 AES-GCM 档案事务中发布。任一声明能力失败均不替换旧档案。
- 档案写入 schema 5，读取 schema 3/4/5；加载旧档案不自动重写。TSE 使用独立的原始参考类，避免 `SpeakerReference` 的 L2 归一化改变其语义。
- 认证通过但 TSE 版本不同的档案保留 CAM++ 能力，TSE 状态为 incompatible，引导重新录入。结构损坏、非有限向量等不能载入。

三段均值算法已有版本号和数值/事务验证；合成中文语音对照尚未证明其分离质量达标，与单参考在真实重叠语音上的质量对比也未完成，不将它当作已通过 P5 的质量选择。

## 连续模型与后续接线

`TseModel.create_stream()`、`TseStream.push()/flush()` 支持任意输入分块，内部最多 640 样本（40 ms），每个输出明确携带 `[start_sample,end_sample)`。完整分析/合成稳态暂留 384～511 样本，首次输出需 512 个输入样本；样本坐标不会因延迟平移。`flush()` 输出精确原始长度，不输出尾部补齐样本。

`TseWorker` 持有单线程、单 ORT session 和独立连续流状态，默认积压容量/最老年龄各 200 ms。故障、超时、取消、乱序使流退休；`close()` 返回 False 明确表示原生调用仍未退出，不能据此新开重叠 worker。ASR 句终不应 reset/flush 连续采集流。

后续 P4 必须同时接入：原始身份观测、采集样本范围、生命周期三类缓存、门控已授权区间、发送器两类音频命令、seal 等待、写入/未知回执及流代次。提取输出不作为身份通过的证据，也不能自动回退混音。

### 合成中文语音开发对照

使用本机 Windows SAPI 的 Huihui / Kangkang 合成独立参考句、目标句和旁人句；没有采集用户麦克风或真人录音。第一段参考与三段原始向量均值分别运行相同模型，所有输出保留原始 169,920 个样本。该小样本只用于发现问题，不作为最终验收集或真人效果结论。

随后使用原离线导出环境，只对同一条单人目标运行官方 `TSE_BSRNN_SPK` 完整 forward、真实权重和相同确定性 dither：官方输出 SI-SDR 为 -11.567013 dB，当前 stateful ONNX 保存的 PCM16 为 -11.567089 dB；公共前缀最大绝对差 3.46e-5，误差相对 RMS 为 -57.60 dB（含 PCM16 量化）。官方默认 iSTFT 输出 169,856 个样本，当前精确保留 169,920 个原始样本，比较使用共同前缀。官方推理输入没有额外增益、标准差归一化或频谱压缩；保存前可选的峰值归一化不改变 SI-SDR。因此这条样本的退化未显示为当前适配器错误，也不能外推为所有真人录音均失败。
