# 点击引导版新手教程：顺序与推进

这是与七天教程并存的一次性点击引导。新用户首次进入仍只走原七日教程。老用户在记忆浏览器重新激活教程时才二选一：点击引导保留七日进度，七日教程沿用原全部重置流程。模块、状态与验证边界见 [开发文档](click-guide-development.md)，原七天内容见 [内容盘点](seven-day-tutorial-content-inventory.md)。

## 两段连续的路线

先认识整个区域，再介绍其中的按钮。所有胶囊内容讲完后才移到角色旁边，不在两个区域之间来回跳。

| 阶段 | 顺序 |
| --- | --- |
| 胶囊聊天框，最多 13 步 | 输入并发送“你好” → 展开历史 → 收起历史 → 悬停打开工具轮盘 → 截图 → 互动道具 → 字幕翻译 → 点歌台 → 导入图片 → 导出对话 → Galgame → 收起聊天框 → 恢复聊天框 |
| 角色旁边的按钮，最多 9 步 | 主按钮总览 → 语音 → Agent 猫爪 → 喵宇宙 → 设置 → 回窝 → 召回（仅实际回窝后）→ 锁定位置 → 完成 |

进度同时显示阶段名和步数，例如“胶囊聊天框 · 1 / 13”。实际跳过的步骤从分子、分母扣除；条件只在到达该步骤时判断，不提前执行未来步骤的业务判断。悬浮按钮打开的菜单和独立页面，其关闭说明属于当前功能内部的返回过程，不新增固定编号。

轮盘顺序与 `COMPACT_INPUT_TOOL_WHEEL_TOOL_ORDER` 一致。首步由用户在真实输入框输入“你好”并按回车发送；真实发送完成后才进入历史展开/收起。提示卡不会抢走输入框焦点。点击展开后短暂高亮完整记录区，下一步同时高亮完整记录区与蓝色收起条，并把 Ghost Cursor 放在条的中央。发送后输入框变空，工具轮盘可用；悬停展开即推进，截图步骤说明可用鼠标滚轮或拖动轮盘切换工具。教程临时把轮盘转到当前介绍的工具，结束时恢复原中心位置。

悬浮部分只介绍主入口。语音说明顺带指出设备、音量和屏幕分享在小箭头里；Agent 说明任务面板可看进度和停止任务；设置概括角色、声音、聊天偏好和记忆。不增加二级菜单逐项教学，也不要求配置服务或授权。

## 用户怎么继续

| 类型 | 当前操作 | 推进条件 |
| --- | --- | --- |
| 胶囊入门 | 输入“你好”并按回车发送 | 发出消息后进入历史；已有草稿或附件时保留原内容，可点“下一步”进入历史。 |
| 悬浮按钮总览 | 看整组悬浮按钮 | 点组内任意真实按钮只进入下一步，不执行该按钮功能；也可点卡片“下一步”。Ghost Cursor 放在语音按钮中央。 |
| 实际点击 | 历史展开/收起、聊天框收起/恢复 | 点高亮目标，且业务状态真的改变后继续。显示 Ghost Cursor。 |
| 悬停 | 打开工具轮盘 | 鼠标移到右侧工具按钮，轮盘展开后继续。也可选择跳过工具。 |
| 轮盘工具 | 截图到 Galgame 的七个高亮按钮 | 点击当前高亮按钮只进入下一步，不执行该功能；也可点卡片“下一步”。显示 Ghost Cursor。 |
| 其他功能说明 | 语音、Agent、社交、设置、锁定 | 可直接点“下一步”。 |
| 返回 | 卡片“上一步” | 返回实际看过的上一步，跳过未展示的条件步骤；悬浮按钮 1/9 返回胶囊聊天框 13/13。若当前已打开子页，先关闭子页，再返回。 |
| 打开后的返回 | 悬浮菜单、独立页面 | 说明当前入口的用途，再引导关闭；关闭完成后继续。嵌套页面先返回上一层。 |
| 可选成对操作 | 回窝与召回 | 回窝可以跳过；只有真实回窝成功才进入召回。 |
| 入口不可用 | 目标缺失、禁用或等待超时 | 给出可见说明和继续通道，不假装业务动作已完成。 |

点开一个新页面后，当前目标是“认清入口，学会返回”。卡片不会承诺在遮罩下自由浏览或完成设置。关闭按钮如果触发保存、确认等业务提示，先解除页面内点击限制，让用户处理提示；真正关闭后才继续。结束整套引导不强行关闭用户已经打开的业务页面。

轮盘的七个按钮在引导中只作入口介绍，不展开道具栏、点歌台、文件选择或导出区域，也不切换翻译与 Galgame 模式。悬浮菜单可以用卡片“收起菜单，继续”返回；从菜单打开独立页面时，切换为页面关闭引导。

## 草稿与操作结果

- 开始时已有草稿或附件：不要求发送“你好”，保留原内容并进入历史。到工具步骤可手动清空草稿以继续轮盘，或跳过工具。
- 轮盘七个介绍步骤不执行真实功能，因此不会生成截图、导入附件、打开页面或更改模式。
- 只有用户亲自按回车才发送“你好”；教程不代为发送、清空草稿、授权或保存导出文件。用户在教程以外主动改变的设置、模式、草稿和附件保留。
- 完成、跳过或异常结束：清除教学展示，恢复聊天框和悬浮按钮的原展示状态；七日教程记录不变。

## 视觉与文案

遮罩使用完整的圆角矩形或圆形开孔，高亮框位于遮罩之上，二者共用同一范围。胶囊总览贴合真实外框；历史收起步骤同时展示记录区和蓝条两个独立开孔/高亮框，蓝条按可见线条测量并保留矩形猫耳。圆形复用七日教程图片，不重复叠加猫耳。Ghost Cursor 位于需要点击的真实按钮中央，包括只推进教程的轮盘工具与悬浮按钮总览。

所有提示卡，包括记忆浏览器的重新激活选择、网页子页返回和桌面原生提示卡，都使用用户提供的背景图片；图片层透明度为 `0.35`，文字与按钮不随背景变淡。卡片避开当前目标和展开的工具轮盘。文案用简短的“用途 + 当前操作”，不堆叠教程机制或实现说明。

## 验收路径

1. 两个阶段都先出现整体高亮，随后按区域内顺序介绍；阶段切换时名称明确，跳过工具或召回后不出现空缺编号。“上一步”遵循实际访问顺序，悬浮按钮 1/9 可返回胶囊聊天框 13/13。
2. 首步输入“你好”并按回车真实发送，随后历史、毛绒球和返回操作由真实点击推进；轮盘由悬停展开。背景点击不能误推进。
3. 逐个点击轮盘七个高亮按钮、或悬浮按钮总览中的任意主按钮时只进入下一步；截图、道具栏、翻译、点歌台、导入、导出与 Galgame 的原功能均不执行。退出教程后按钮恢复正常。设置子页和嵌套子页仍须逐层关闭后才继续；关闭确认可操作，未关闭不提前前进。
4. 带草稿进入、跳过工具、跳过或体验回窝，都能继续，并保留用户数据。
5. 网页和桌面分别检查开孔、卡片遮挡、图片可读性和长文案高度稳定性；锁定角色后卡片仍可点击，也能再次解锁。退出后正常聊天、角色拖动和原七日教程仍可使用。

实际测试覆盖与尚未验证的平台见开发文档，不把网页结果等同于完整桌面体验。
