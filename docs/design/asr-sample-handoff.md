# 独立 ASR 回合交接的采样归属

本修复属于 #3149 的候选准入实现。旧轮已经交付的 PCM 可能仍有不足一个
Silero 窗口的残余尚未参与推理；它不属于后继待发缓冲，不能据此认定后继丢失首字。
固定 512 采样点分包掩盖了这一问题，桌面 soxr 实际输出的 489/490 分包可复现。

## 归属与交接

- 以输入身份和归一化 16 kHz 采样区间 `[start, end)` 标识音频。
- 已准入 provider 回合的完整输入块，在异步检测前进入串行派发队列。
  成功入队确定其归属，不代表供应商已确认接收；写入不确定的保护保持不变。
- provider 封口在检测器锁内读取已承诺交付的末尾，防止等待锁期间入队的音频被遗漏。
- 模型上下文保留。跨界窗口只有边界后的时长计入新候选；概率仍是窗口级模型证据。
- 原始 VAD 活动与候选准入保持分离，不改变 provider 结束权或 SmartTurn 的延续语义。
- 已上传重叠回合沿用现有结果顺序与证据，不要求从本地缓冲重新取回。

## 缓冲与准备期间的输入

缓冲中的 PCM 与采样区间一起裁剪、迁移。候选取音频时校验请求区间的连续覆盖，
旧候选之前的缺口不影响完整的新候选；新候选自身缺少开头、存在内部缺口或重叠则失败。
不通过截短请求、填静音或增大容量绕过缺失检查。

已确认的后继前缀在回合准备和状态通知期间仍由生命周期持有。新输入追加到同一前缀，
直到派发队列同步接收后才释放；不能保存旧字节快照并在跨 await 后覆盖新尾音。
准备期间容量沿用八秒上限，达到上限时保留现有内容并明确失败，不滚动删除首字。

## 失败与取消

范围缺失、范围不连续、容量不足分别记录数值诊断。新错误不加入自动重连白名单。
旧身份结果不能准备新回合；关闭前已交付的输入不会撤回，关闭后的迟到检测不能继续派发。
会话、路由和输入代际校验继续约束每个异步交接。

## 验证边界

定向测试使用实际 soxr 分包和位置编码 PCM，比较真实派发内容，而非仅检查无异常。
覆盖非对齐与对齐分包、残余长度、连续回合、已上传重叠回合、真实缺口、关闭、
检测 await 与 endpoint/final 交错、封口等锁期间继续入队，以及回合准备期间收音。
模型概率与 provider I/O 使用 fake；不能据此宣称真实短指令识别、噪声准入或网页/Electron
设备体验已验收。原生直连语音、声纹、唤醒词、AGC 和强制断句不在本次改动范围。

本轮定向回归 278 项通过，未运行全量测试；范围缓冲、准入 gate、生命周期三模块
合计语句覆盖率 93.68%。静态检查通过。现有 websockets 模块更名弃用警告仍存在。
回归同时修正 submit 恢复分支的显式类型返回形式，使既有返回契约守卫通过，
不改变恢复结果、重试策略或交付阶段。

Core review 应重点检查封口锁内边界读取、提前入队的身份保护，以及 pending 前缀在
准备回调期间的唯一持有者。真实短词贴近交接边界时，旧采样不再计入准入时长，
可能略晚通过；需要设备实测，不能用降低门槛抵消。未重启运行中的后端，部署此版本后
还需验证网页/Electron 中的连续两句话、快速接话和“停／取消”。
