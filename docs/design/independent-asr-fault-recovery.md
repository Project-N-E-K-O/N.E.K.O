# 独立 ASR 异常结算与恢复

本实现随 #3149 整合验证。目标是明确故障后的旧回合结算和后续输入恢复；环境音持续被云端判成人声、尚未收到端点的长等待仍属独立问题。

## 故障与预算

- 按可信错误码和来源分类。Qwen 读取断连、收到端点后 final 超时允许恢复；写入不确定、凭据错误、检测器／顺序／身份错误和未知错误保持安全停止。
- Qwen worker 的 stalled item 不再伪造空 final，改为明确的 `ASR_PROVIDER_FINAL_TIMEOUT`。普通长句、短暂停顿不触发恢复。
- 替代连接最多尝试两次，使用原有连接操作，恢复总预算 12 秒，包含旧连接清理和 provider 失败前已接受回调的排空时间。通知另有至多 1 秒的发送保护，不允许通知阻塞继续接收或重试音频。
- 连续故障共享尝试额度；握手成功不清零。Core 真正交付有效 final 后才清零，echo 拒绝、空结果、路由失效和恢复期间完成的旧结果都不补额度。新用户会话重新创建预算。

## 所有权与结算

恢复操作固定 `recovery_id`、会话／输入／lease／route 代次、旧连接和绝对期限。关键等待后重新验证归属。用户静音、结束会话和接管会取消操作。

final 接受与有序队列提交在同一锁区间内完成。恢复与 final 竞争同一个锁，未接受回合释放自己的预留、预览和暂停；partial 永远不升级为 final。旧 provider 在退休后不能回调到替代连接。

恢复首先阻断旧连接音频，保留已接受 final 的原有交付身份。若这项 Core 交付超过恢复预算，恢复按时失败并停止接收、提示重试；**已经接受的 Core 交付沿原有生命周期独立完成**，队列结清后才执行会撤销其身份的最终路由清理。这里没有新增无限重连或额外等待任务。用户主动取消仍按原语义终止交付。

## 恢复期间的输入

不重传旧连接已上传或结果不确定的音频。若故障时旧句仍在本地 VAD 的 active 状态，只继续本地观察，待原有 idle／pause 边界后重置候选。边界读取使用真实 gate 状态，不使用可能滞留的 candidate 标志，也不新增静音阈值。

边界后的新音频复用串行输入、候选准入和缓冲：未确认候选仍受原候选预算限制；确认后的待发语音保持最多 8 秒。超限整句失败并明确提示，不滚动删去首字。替代连接采用后按原顺序发送，只准备一次新回合。

## 显式有界收尾

支持该能力的 Qwen session 提供 `finish_and_drain(deadline=...)`。调用者先停止该连接的新输入，然后按 FIFO 排空已接受音频及重采样尾巴、发送 `session.finish`，保持身份直到 final 回调完成。`session.finished` 本身不代表回调结算完成。期限、取消或回调错误均不会报告成功。

这是显式能力，没有自动长等待触发器。普通 `close()` 继续使用取消语义；用户结束会话不会因此额外生成回复。其他供应商默认不支持此能力。

## 前端与诊断

自动恢复使用 STARTED／READY／FAILED／TURN_INCOMPLETE 四类状态，与取消静音的恢复窗口分开。事件带会话、lease、route 和恢复身份，经现有控制通道送往录音窗口；READY 不开麦、不解除静音。旧操作和旧 socket 状态不能覆盖当前状态。上一句未完成提示同步八种语言。

诊断区分 `awaiting_endpoint` 和 `awaiting_final`，记录故障码、身份、上传及待发数量、尝试次数和耗时，不新增原始音频或转写文本日志。

## 验证与边界

定向故障注入覆盖 final／timeout 竞争、迟到回调、连续失败、旧音频不重传、完整新音频有序发送、容量上限、静音取消、预算耗尽仍保护已接受 final，以及收尾后立即 finished。SmartTurn 的 lease 退休和新句重建、16kHz／48kHz 输入归一化有自动化覆盖，模型和云端由 fake 替代。前端覆盖状态归属、真实 PCM 上传开关和八种语言键。

没有运行全量测试，也没有将自动化结果冒称真实网页／Electron 麦克风验收。需要在整合环境的新语音会话中继续实测。声纹、准入门槛、AGC、云端 VAD 参数及原生直连语音行为保持原有边界。
