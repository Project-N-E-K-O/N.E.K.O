# プライバシーポリシー

本ポリシーは Project N.E.K.O. ドキュメントサイトに適用されます。

## 選択について

アクセス解析は任意です。許可するまで Google Analytics は読み込まれず、拒否してもドキュメントの利用は制限されません。

Google Analytics は読み込まれず、Google Analytics へのリクエストも送信されません。**許可**または**拒否**を選ぶまで、同意バナーは選択を保存しません。

## アクセス解析を許可した場合に使用される情報

アクセス解析を許可した場合、測定 ID `G-N4QZK4PHE3` を使用して Google Analytics 4 を読み込み、どのドキュメントページが役立っているか、訪問者がどのようにサイトへ到達したかを把握するためにページビューイベントを送信します。N.E.K.O. の Steam ページへのリンクが選択された場合は、サニタイズされた遷移先 URL、CTA の配置、サニタイズされた現在のページ URL、ページタイトルを含む `steam_cta_click` イベントも送信します。

Google Analytics は、ページ URL とタイトル、参照元、ブラウザーや端末の情報、おおよその地域などを処理する場合があります。本サイトの設定では、広告ストレージ、広告ユーザーデータ、広告のパーソナライズ、Google シグナル、広告パーソナライズシグナルを無効にしています。

この情報は集計レポートとドキュメントの改善にのみ使用されます。広告トラッキングと広告のパーソナライズは常に無効です。

## 情報の取り扱い

Google Analytics は本サイトに代わってアクセス解析情報を処理します。本サイトは、アカウント認証情報、非公開のメッセージ、フォームの内容、その他の機微な情報をアクセス解析で意図的に送信しません。

アクセス解析イベントを送信する前に、ページ URL には許可された `utm_source`、`utm_medium`、`utm_campaign`、`utm_content`、`utm_term` のキャンペーンパラメーターのみを残し、各値を 100 文字に制限します。その他のクエリパラメーターと URL フラグメントは削除されます。Steam の遷移先 URL も、クエリパラメーターとフラグメントを除いて送信されます。

ブラウザーは、ローカルストレージの `neko.docs.analytics-consent.v1` に選択を保存します。保存されるのは選択、形式のバージョン、保存時刻だけです。選択は 180 日後に期限切れとなり、その後は再度確認が表示されます。

GA4 の「データ保持」設定の対象となるユーザーレベルおよびイベントレベルのデータは、最長 14 か月保持されます。プロパティ管理者は 2 か月に短縮できます。この設定は集計済みの標準レポートには影響しません。詳しくは [Google Analytics のデータ保持](https://support.google.com/analytics/answer/7667196?hl=ja) を参照してください。

本サイトはホスティングに外部サービスを利用し、Steam などの外部ページを開く場合があります。これらのサービスはそれぞれのポリシーに従って情報を取り扱います。

## 選択の変更または撤回

各ドキュメントページ下部に常時表示される **Cookie 設定**から、いつでもアクセス解析を許可または拒否できます。以前の同意を撤回すると、アクセス解析の同意状態を拒否に変更し、スクリプトから削除可能な `_ga` Cookie の削除を試み、Google タグを読み込まずにページを再読み込みします。ブラウザーから本サイトの保存データを削除すると、保存された選択もリセットされます。拒否してもドキュメントの利用には影響しません。
