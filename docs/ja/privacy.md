# プライバシーポリシー

**最終更新日：2026年8月5日**

本ポリシーでは、Project N.E.K.O. ドキュメントサイトがアクセスに関する情報をどのように取り扱うか、またプライバシーに関する選択をどのように管理できるかを説明します。

## 1. 本ポリシーの適用範囲

本ポリシーは Project N.E.K.O. ドキュメントサイトに適用されます。ドキュメントサイトから開く GitHub、Steam、Google、その他の外部サイトでは、それぞれのプライバシーポリシーに従って情報が取り扱われます。

## 2. 処理する可能性がある情報

ドキュメントサイトにアクセスすると、次の種類の情報が処理される場合があります。

- **ページ閲覧情報：** 閲覧したドキュメントページ、参照元ページ、基本的なアクセス状況など。
- **ブラウザーと端末の情報：** ブラウザーの種類、端末の区分、おおよその地域など。
- **操作情報：** ページビューや、Project N.E.K.O. の外部製品ページへのリンク操作など。
- **プライバシー設定：** アクセス解析を許可したかどうかと、その選択を記憶するために必要な最小限の状態がブラウザーに保存されます。

ドキュメントサイトは、アカウント認証情報、非公開のメッセージ、フォームの内容、その他の機微な情報をアクセス解析で意図的に収集または送信しません。

## 3. 情報を使用する目的

アクセス解析情報は、次の目的にのみ使用します。

- **ドキュメントの改善：** 役立つ内容と改善が必要なページを把握します。
- **ナビゲーションの改善：** 訪問者がどのようにドキュメントサイトを見つけ、閲覧しているかを把握します。
- **外部リンクの評価：** ドキュメントが Project N.E.K.O. の製品ページを見つける助けになっているかを把握します。
- **集計レポートの作成：** 全体的なアクセス傾向を確認し、ドキュメントの保守に役立てます。

広告トラッキング、広告ユーザーデータ、広告のパーソナライズ、および関連する広告シグナルは常に無効です。

## 4. Cookie、ローカルストレージ、アクセス解析技術

ドキュメントサイトでは、次の2種類のブラウザー技術を使用します。

- **必須のローカル設定保存：** アクセス解析を許可または拒否した選択を記憶します。この目的に必要な最小限の状態だけを保存します。
- **任意のアクセス解析技術：** アクセス解析を許可した場合、Google Analytics 4 を読み込み、ドキュメントの閲覧と限定的な操作に関する集計レポートを作成します。

明示的に許可するまで、任意のアクセス解析は読み込まれず、Google Analytics への解析リクエストも送信されません。詳しくは [Cookie ポリシー](/ja/cookies) を参照してください。

## 5. 第三者による情報の取り扱い

- **Google Analytics：** 許可された後、ドキュメントサイトに代わって任意のアクセス解析情報を処理し、サービスのポリシーとプロパティ設定に従って関連データを保持します。
- **ホスティングと外部ページ：** ドキュメントサイトは外部のホスティングサービスを利用し、GitHub や Steam などの外部ページを開く場合があります。これらのサービスはそれぞれのポリシーに従って情報を取り扱います。

Google Analytics の保持方法については、[Google Analytics のデータ保持](https://support.google.com/analytics/answer/7667196?hl=ja) を参照してください。

## 6. データの最小化と保持

アクセス解析情報を送信する前に、ページ URL と遷移先 URL を処理し、集計レポートに必要な限定的な情報だけを保持します。不要なクエリデータと URL フラグメントは削除し、情報が意図せず送信されるリスクを低減します。

ローカルのプライバシー設定と任意のアクセス解析データは、上記の目的に必要な期間に限り、関連サービスの設定に従って保持されます。プライバシー設定は定期的に期限切れとなり、その後は再度確認が表示されます。

## 7. 選択と管理

各ドキュメントページ下部に常時表示される **Cookie 設定**から、いつでもアクセス解析を許可、拒否、または撤回できます。

以前の同意を撤回すると、その後のアクセス解析を停止し、本サイトから削除できる解析用 Cookie の削除を試みたうえで、アクセス解析を有効にせずページを再読み込みします。ブラウザーから本サイトの保存データを削除すると、保存された選択もリセットされます。

アクセス解析を拒否しても、ドキュメントの通常の閲覧や利用には影響しません。

## 8. 外部リンク

ドキュメントサイトには、GitHub、Steam、Google、その他の第三者サイトへのリンクが含まれる場合があります。ドキュメントサイトを離れた後は、各第三者がそれぞれのポリシーに従って関連情報を取り扱い、Project N.E.K.O. ドキュメントサイトはそのプライバシー慣行を管理できません。

## 9. 本ポリシーの変更

ドキュメントサイトの機能、アクセス解析方法、または適用される要件の変更に応じて、本ポリシーを更新する場合があります。更新版は本ページに掲載し、ページ上部の最終更新日を変更します。

## 10. お問い合わせ

プライバシーに関する質問は、機微な情報を公開せずに [Project N.E.K.O. GitHub リポジトリ](https://github.com/Project-N-E-K-O/N.E.K.O/issues)からお問い合わせください。
