# プライバシーポリシー

本ポリシーは Project N.E.K.O. ドキュメントサイトに適用されます。

## 選択について

アクセス解析は任意です。許可するまで Google Analytics は読み込まれず、リクエストも送信されません。**許可**または**拒否**を選ぶまで、同意バナーは選択を保存しません。拒否してもドキュメントの利用は制限されません。

## アクセス解析を許可した場合に使用される情報

アクセス解析を許可した場合、Google Analytics 4 を読み込み、どのドキュメントページが役立っているか、訪問者がどのようにサイトへ到達したかを把握するために、ページビューと限定的な操作イベントを送信します。N.E.K.O. の Steam ページへのリンクが選択された場合は、ドキュメントから製品ページへの移動状況を把握するため、その外部リンク操作を記録します。イベントには、集計レポートに必要な、処理済みのページまたは遷移先情報と基本的なページコンテキストのみが含まれます。

Google Analytics は、ページ URL とタイトル、参照元、ブラウザーや端末の情報、おおよその地域などを処理する場合があります。本サイトの設定では、広告ストレージ、広告ユーザーデータ、広告のパーソナライズ、Google シグナル、広告パーソナライズシグナルを無効にしています。

この情報は集計レポートとドキュメントの改善にのみ使用されます。広告トラッキングと広告のパーソナライズは常に無効です。

## 情報の取り扱い

Google Analytics は本サイトに代わってアクセス解析情報を処理します。本サイトは、アカウント認証情報、非公開のメッセージ、フォームの内容、その他の機微な情報をアクセス解析で意図的に送信しません。

アクセス解析イベントを送信する前に、ページ URL と遷移先 URL を処理します。帰属分析に必要なキャンペーン情報のみを保持する場合があり、その他のクエリデータと URL フラグメントは削除します。保持する内容にも制限を設け、情報が意図せず送信されるリスクを低減します。

ブラウザーには、アクセス解析に関する選択と、その選択を記憶するために必要な最小限の状態だけが保存されます。選択は定期的に期限切れとなり、その後は再度確認が表示されます。

Google Analytics は、プロパティのデータ保持設定に従って関連データを処理し、その期間はプロパティ管理者が調整できます。集計済みの標準レポートには、異なる保持方法が適用される場合があります。詳しくは [Google Analytics のデータ保持](https://support.google.com/analytics/answer/7667196?hl=ja) を参照してください。

本サイトはホスティングに外部サービスを利用し、Steam などの外部ページを開く場合があります。これらのサービスはそれぞれのポリシーに従って情報を取り扱います。

## 選択の変更または撤回

各ドキュメントページ下部に常時表示される **Cookie 設定**から、いつでもアクセス解析を許可または拒否できます。以前の同意を撤回すると、拒否の選択を記録し、その後のアクセス解析を停止し、本サイトから削除できる解析用 Cookie の削除を試みたうえで、アクセス解析を有効にせずページを再読み込みします。ブラウザーから本サイトの保存データを削除すると、保存された選択もリセットされます。拒否してもドキュメントの利用には影響しません。
