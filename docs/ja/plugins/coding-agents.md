# AI エージェントで作る

コードを書く必要はありません。AI コーディングツールを 1 つ選び、一文を送れば、あとは「許可」とボタンを押すだけです。

**作れるものの例**：猫娘が水分補給を教えてくれるプラグイン、会話中に呼べる天気ツール、今日の予定を表示する小さなパネルなど。一文で説明できるものなら作れます。

## 4. ルート A：AI に最初から全部やってもらう

1. Agent で**空のフォルダを開く**（場所はどこでも。このプロジェクト専用に）。
2. 上の「ルート A」の文を送る。
3. AI が操作の実行を求めてきたら「許可」を押す。ダウンロードや設定をすべて自分で行うので時間がかかる。URL を教えてくれたら Web ページを開き、初回は案内どおりに画面でモデル API を入力する。
4. Web のプラグイン管理で「起動」を押して試す。以降の変更は自動でリロードされる。
5. 次回続けるときは AI に「N.E.K.O を起動して」と言うだけ。

![プラグイン画面右上に「起動」「リロード」ボタン](/images/plugins/onboarding/neko-plugin-detail-ja.png)

## 5. ルート B：インストール済みの N.E.K.O を使う

1. まず Git をインストール：[公式ダウンロードページ](https://git-scm.com/downloads)で自分の OS を選び、インストーラーを進める。
2. N.E.K.O のプラグイン管理を開き、左の「プラグイン制作」で「新規プラグイン」を押す。名前と ID を入力し、親フォルダを選んで「プレビュー」で標準ファイルを確認したら「プラグインを作成」。**このプロジェクトフォルダの場所を覚えておく**。

   ![プラグイン制作で新規作成し、標準ファイルをプレビュー](/images/plugins/onboarding/neko-studio-new-ja.png)

3. Agent で**このプラグインプロジェクトフォルダを開く**。
4. 上の「ルート B」の文を送る。
5. プラグイン画面で「起動」を押して試し、AI が直すたびに「リロード」を押す。エラーが出たら、そのまま貼って AI に送る。

![プラグイン画面右上に「起動」「リロード」ボタン](/images/plugins/onboarding/neko-plugin-detail-ja.png)

## 6. ほかの人に配りたいとき

ルート B ならワークベンチの「パッケージをダウンロード」、ルート A なら AI に頼むだけで、`.neko-plugin` ファイルを書き出せます。相手は「プラグイン管理」の「インポート」でそれを読み込むだけ。Market への公開にはソース版が必要なので、直接公開できるのはルート A だけです。[プラグインを公開](/ja/plugins/cli)を参照してください。

![配布した .neko-plugin を相手が「インポート」で読み込む画面](/images/plugins/onboarding/neko-import-dialog-ja.png)

> 新しいプロジェクトに AGENTS.md がない場合は N.E.K.O のバージョンが古いので、最新版に更新してからもう一度お試しください。
