# AI エージェントで作る

コードを書く必要はありません。N.E.K.O が AI 向けの説明書（AGENTS.md）付きでプラグインプロジェクトを作り、AI がコードを書いて実行まで行い、あなたはボタンを押すだけです。

**作れるものの例**：猫娘が水分補給を教えてくれるプラグイン、会話中に呼べる天気ツール、今日の予定を表示する小さなパネルなど。一文で説明できるものなら作れます。

## 1. 2 つ用意する

- **インストール済みの N.E.K.O**：デスクトップ版または [Steam 版](https://store.steampowered.com/app/4099310/__NEKO/)。
- **AI コーディングツール 1 つ**：下から選んでインストール・ログインします。迷ったら公式チュートリアルを先に見てください。

<CodingAgentOnboarding section="agent" />

## 2. 「プラグイン制作」で「新規プラグイン」を押す

N.E.K.O のプラグイン管理を開き、左の「プラグイン制作」で「新規プラグイン」を押します。名前と ID を入力し、親フォルダを選んで「プレビュー」を押すと、AGENTS.md や CLAUDE.md などの標準ファイルが見えます。確認したら「プラグインを作成」。**このプロジェクトフォルダの場所を覚えておいてください**。

![プラグイン制作で新規作成し、標準ファイルをプレビュー](/images/plugins/onboarding/neko-studio-new-ja.png)

## 3. Agent でそのフォルダを開く

第 1 步で選んだカードの説明どおりに、そのアプリで新しいプラグインフォルダを開き、ファイル編集と操作の実行を許可します。

## 4. この文をコピーして AI に送る

<CodingAgentOnboarding section="prompt" />

AI は自分で AGENTS.md を読み、コードを書き、チェックまで実行します。操作の実行を求められたら「許可」を押すだけ。困ったときは AI がやさしい言葉で聞いてきます。

## 5. ワークベンチで動きを確認

プロジェクト詳細で「プラグイン管理で開く」を押し、プラグイン画面右上の「起動」で試せます。AI が直すたびに「リロード」を押すだけ。プロジェクトに問題がないか確かめたいときは、ワークベンチの「公開」タブに「チェックを実行」があります。機能を変えたいときは、そのまま AI に話しかけてください。

![ワークベンチのプロジェクト詳細：再読み込み・フォルダーを開く・プラグイン管理で開く](/images/plugins/onboarding/neko-studio-project-ja.png)

![プラグイン画面右上に「起動」「リロード」ボタン](/images/plugins/onboarding/neko-plugin-detail-ja.png)

## 6. ほかの人に配りたいとき

ワークベンチの「パッケージをダウンロード」で `.neko-plugin` ファイルを書き出せます。相手は「プラグイン管理」の「インポート」でそれを読み込むだけ。Market に公開する場合は[プラグインを公開](/ja/plugins/cli)を参照してください。

![配布した .neko-plugin を相手が「インポート」で読み込む画面](/images/plugins/onboarding/neko-import-dialog-ja.png)

> 新しいプロジェクトに AGENTS.md がない場合は N.E.K.O のバージョンが古いので、最新版に更新してからもう一度お試しください。
