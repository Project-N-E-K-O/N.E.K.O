# 独立 ASR 候选准入：#3149 整合实测

## 行为与开关

设置后端环境变量 `NEKO_ASR_ADMISSION=1`，新建独立 ASR 会话时启用。默认 `0`；策略在 DetectorRuntime 创建时固定，运行中不热切换。停止会话并在关闭开关的后端重建会话可回滚，已拒绝音频不会补传。该实验开关与资源优化开关独立。

采用当前实验参数：224ms 有效人声、480ms 有限窗口、65% 占比、96ms 最大间断、640ms 候选等待预算。没有启用未经验证的更短指令窗口，没有全局提高到 350ms，没有改变 AGC 参数或其已经修正的时间单位。

入口复用一次 Silero 推理，分离两类事件：SmartTurn 保留原始活动/恢复事件；ASR runtime 只用准入事件开启新用户回合。RNNoise 资源优化不能关闭准入；缺少 RNNoise 时使用 Silero。启用实验后 Silero 不可用会明确关闭本次不安全输入路径，不转成持续上传。

## 回合、缓冲与证据

- 规范化 PCM 在异步检测前进入已有缓冲，未承诺候选最多保留 700ms。候选本身仍受 640ms 证据预算约束，不使用 8 秒待发送容量作为准入窗口。
- 音频采样位置随检测身份传递；准入时裁掉已经拒绝的前驱，只保留本候选及最多 128ms 前置音频。检测迟到且首部已经淘汰时明确报告背压，不悄悄上传缺首字的句子。
- 准入后才准备回合，再经原有串行 dispatcher 发送前置音频；已经承诺的前缀沿用保护/失败逻辑，活跃句子的尾音和静音连续上传。
- 准入证据快照绑定 turn token。它描述准入判定所观察的采样范围，不是整句最终长度或 ASR 文本置信度；等待网络 final 不增加人声时长。RNNoise、播放状态没有采集到时保留未知值。
- Provider seal 退休本候选准入资格，旧 final 不重置后继检测器。句内 pause 后的潜在重叠起音重新确认，既有重叠记录携带各自证据；供应商延迟端点不会让 32ms 恢复脉冲得到新回合资格。
- SmartTurn 的未准入候选完成后，不等待不存在的供应商 final；后继正常语音可继续。

## 转写防线和 Core 回归报告

共享策略只处理语音来源、首尾去空白/标点后整段精确匹配填充词、且有不足的人声证据的输入。缺失证据放行；明确控制词、完整内容以及已确认的短回应放行。局部概率不被命名为 ASR 置信度。

partial 暂存最多一个、绑定 turn token 的最新短填充词；文本扩展为完整句子后仅显示最新完整预览。final 拒绝沿用空 final 的正常结算和 preview 清理，dispatcher 继续处理下一轮。清理带原有 `asr_turn_id`，不能修改后继预览。

Core 改动用于保证拒绝在用户活动、takeover、历史/插件广播及回复排队之前完成。此前只要收到转写就可能进入这些副作用；现在有明确不足证据的孤立填充词提前结束交付，并由现有 finally 释放本轮。新增事件字段可缺省，不改变既有无证据调用的行为。风险主要是身份传递、重叠回合、预览所有权和轻声/短指令误拒，应重点 review。

## 验证与已知限制

自动化检查实际准备次数、传输 PCM 字节及次序、回合证据、final/preview 调用与回复入口。覆盖资源优化开/关、10/20/32ms 输入块、RNNoise 与 Silero 分歧、检测故障、连续拒绝后恢复、延迟端点、迟到 final、后继预览及 SmartTurn。

既有 `voice-chain` 日志/生命周期指标提供传输字节、回合准备、回复排队及 TTS 交付记录；新增 `voice-admission` 提供候选身份、采样位置、观察/人声时长、概率和判定原因。不记录原始音频或转写文本。

本次没有修改网页/Electron 消息格式，继续使用带回合身份的 preview 协议。自动化协议检查不能代替 Electron 真机及麦克风实测。

已知环境录音在 16kHz 和 48kHz＋RNNoise＋现有 AGC 两条离线路径均被判为持续人声；本改动不保证挡住这种持续高分误判。详见 [录音回放](benchmarks/voice-admission-local-2026-09-23.md)。原生直连语音路径不在本次保护范围内。“停／取消”、真实轻声和正常“嗯”的用户录音仍需实测，不能以合成概率测试代替识别率结论。

验收承诺分别统计：入口拒绝不上传、不准备/打断新回合；final 拒绝不产生后续 LLM/TTS。活跃句子中已经上传的音频和必要尾音无法追回 ASR 费用。阶段 D 的 AGC 调参留到这版入口方案完成对照后单独进行。
