# 独立 ASR 的可靠收尾与恢复分类

适用分支：`codex/integrate-voice-prs-v4`（PR #3149）。实施基线：`761fbcc5`。

## 问题与结果

本轮修复两类相互独立的故障：worker 等待子任务退出时再次被取消，跳过物理连接关闭；激活输入的保护标记覆盖原始故障码，令允许恢复的读断开或 final 超时变成保护性停麦。

原先 Session 可以返回关闭成功，而本地 WebSocket 和服务端连接仍存活。现在物理连接登记到请求队列持有的资源收尾记录；Session、sender 与 worker 复用同一个收尾任务。取消等待者不会取消底层关闭。物理连接关闭与子任务退出分别确认，不能仅依据协议 `closed` 事件或 worker 已结束确认退休。

错误分类依据原始机器码和来源。保护标记继续限制旧音频重传，并提供交付风险诊断。现有已知交付错误保留原有通知；凭据、检测器、未知错误以及恢复终态不会被保护标记改写。恢复白名单、最多两次替代建连、12 秒总预算不变，旧连接退休仍计入恢复预算。

## 资源所有权与顺序

新中立模块 `main_logic/asr_client/connection_cleanup.py` 只管理物理资源及关联任务，不管理音频账本或语音回合。Qwen、Step、OpenAI 在连接创建后、下一次异步操作前登记连接，创建子任务后同步登记。

异常退出先阻断旧输入，启动一次性物理关闭，再有界等待相关任务退出。正常 finish 先保留已有 final 等待及派发顺序。Qwen clear、Step clear/reset 只有在旧连接完成退休后才能替换连接；Step 保留并发 shutdown/clear 优先于 reset 的规则。

每条连接的物理收尾预算为 2 秒，其中保留四分之一预算用于强制终止和确认释放。正常关闭异常但强制终止确认资源释放，可以成功退休，同时记录关闭异常类型。关联任务退出等待为 1 秒；无法确认资源释放或任务退出时，结果为失败，并且后续重复关闭不能改写首次失败。

Session 保留调用方取消不传播到已有关闭任务的规则。共享 shutdown 在物理关闭之后等待 provider 子任务和 Session 任务，排除当前任务及回调中的关闭等待者，防止相互等待。退休失败不递归触发错误恢复。

关闭期间迟到返回的连接立即进入收尾，并独立保存归属失败结果。即使 worker 将异常转成协议事件后正常返回，较早的资源快照也不能让 Session 误报成功。定向反例在禁用此失败记录时会误报成功，修复后保持失败且仍关闭迟到资源。

取消型 `close()` 在同步阻断输入时启动资源收尾，避免 Qwen 的 finish 确认等待超过恢复流程的 2 秒退休预算。显式 `finish_and_drain()` 仍在 final 派发后调用 close。真实 WebSocket 测试证明：服务端不回复 finish 时，新实现按时关闭；在内存替换为修复前的 close 后，同一用例按预期超过 2 秒。

Python 不能强制杀死拒绝取消的任意协程；本实现保证有界报告失败、禁止不安全的后续建连，不承诺此类协程一定已退出。

## 回归与证据

修改前的本机真实 WebSocket 复现共 9 个组合：三个 worker 分别配合立即返回、让出一次执行权、稍晚返回的错误回调。基线为 3 失败、6 通过；失败组合是让出一次执行权，Session 已关闭但服务端仍观察到存活连接。

定向验证覆盖：

- 三个 worker 的本地任务、本地连接状态与服务端关闭观察。
- Qwen/Step clear 时关闭握手异常，经强制终止确认旧连接释放后才创建后继连接。
- 并发及重复 close、取消关闭等待者、worker 收尾期间再次取消。
- 关闭异常、关闭协程拒绝取消、关联子任务拒绝取消，失败结果不能变成成功。
- 已接受 final 在随后退休失败时只派发一次；finish 保留 16kHz/48kHz 尾音。
- 激活后第一句完成、发生读断开、恢复后第二句，旧音频不重传，后继音频有序。
- 退休失败禁止替代建连；迟到事件、关麦、预算耗尽、真实交付异常、未知错误仍保留原有保护。
- 共享 Session 及其他 worker 的既有契约定向回归，Soniox 受保护输入禁止自动重放。

最终定向组合的 386 项 Python 测试全部通过，另有 38 项前端恢复及交付提示测试通过；Ruff 与 diff 空白检查通过。没有运行全量测试。自动化中的供应商协议通过本机 WebSocket 或明确的测试替身复现，没有使用真实云端账户验证全部供应商。网页、Electron 与真实设备效果仍需整合环境实测，尤其是连续两句话、快速接话及恢复中关麦。

## Review 边界

运行时代码仅涉及独立 ASR 的共享 Session、资源收尾、三个 worker 和恢复分类。Core 组装与前端协议没有新增状态，复用既有恢复成功、失败及重说提示。

主要回归风险是内部换连接与 shutdown 的竞争、final 派发和资源退休的先后顺序、第三方连接实现的关闭证明。三个已接入 worker 有物理资源证明；其他 worker 仅做共享 Session 兼容性回归，不宣称同等资源保证。

声纹、唤醒词、AGC、准入阈值、供应商端点参数及原生直连路径未调整，也未增加固定时间强制断句。环境音误准入、短词识别准确率、云端持续不判结束仍是独立问题。
